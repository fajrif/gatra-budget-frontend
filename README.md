# Gatra Budget Frontend

React SPA starter kit built with Vite + TailwindCSS + React Query.

## Quick Start

```bash
npm install
npm run dev     # dev server on port 5173 (proxies /api to :8080)
```

Ensure the backend is running on port 8080 first.

## Commands

```bash
npm run dev      # development server
npm run build    # production build
npm run lint     # ESLint
npm run preview  # preview production build
```

## Stack

- React 19 + Vite
- TailwindCSS + shadcn/ui components
- React Query (@tanstack/react-query) for server state
- React Hook Form + Zod for form validation
- AG Grid v35 for data tables
- React Router v7
